En Make Space Madrid nos entrevistan para [la Hora Maker](https://lahoramaker.com/).

[Echidna Shield - una placa diseñada para la educación](https://www.youtube.com/watch?v=n14cTubcW8U)

La Hora Maker ofrece semanalmente las novedades relacionadas con el mundo maker: da a conocer el movimiento al público general, destaca los principales eventos del mismo y habla de tecnologías para la fabricación personal, herramientas para la fabricación digital, etc.
