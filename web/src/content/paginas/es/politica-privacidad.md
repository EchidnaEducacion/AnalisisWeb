Esta web es de Echidna Educación, una asociación sin ánimo de lucro. La hemos hecho para que puedas leerla sin dejar datos personales: no tiene registro de usuarios, ni comentarios, ni *cookies* de publicidad o de seguimiento.

## Responsable

El responsable de los datos es **Echidna Educación**. Para cualquier consulta sobre esta política o sobre tus datos, escríbenos desde la página de [contacto](/contacta/).

## Qué datos tratamos

### Formulario de contacto

Si nos escribes desde el formulario de contacto, recibimos tu nombre, tu correo electrónico y tu mensaje. Los usamos solo para responderte y no los cedemos a nadie. El formulario se envía a través de un servicio externo de formularios, que nos hace llegar el mensaje por correo.

Conservamos los mensajes mientras sean necesarios para atender tu consulta.

### Estadísticas de visitas

Contamos las visitas con GoatCounter, un servicio de código abierto que no usa *cookies* ni guarda datos personales. Solo registra qué páginas se visitan, desde qué web se llega y datos generales como el tipo de navegador o el país, sin identificar a quien visita la web.

### Preferencias en tu navegador

Si eliges el modo claro u oscuro, la web lo recuerda guardándolo en tu propio navegador. Ese dato no sale de tu equipo y puedes borrarlo cuando quieras desde los ajustes del navegador.

## Servicios de terceros

- **Alojamiento**: la web está alojada en GitHub Pages. Como cualquier servidor, GitHub registra la dirección IP de las visitas por motivos de seguridad. Consulta la [declaración de privacidad de GitHub](https://docs.github.com/es/site-policy/privacy-policies/github-general-privacy-statement).
- **Tipografías**: las fuentes de letra se cargan desde Google Fonts, que recibe la dirección IP de quien visita la web.
- **Vídeos y presentaciones**: algunas páginas incluyen vídeos de YouTube u otros contenidos de otras webs. No se cargan hasta que pulsas sobre ellos; a partir de ese momento, ese servicio puede usar sus propias *cookies*.
- **Enlaces**: la web enlaza a otros sitios (repositorios, guías, distribuidores). Al visitarlos se aplica su propia política de privacidad.

## Tus derechos

Puedes pedirnos en cualquier momento acceder a tus datos, corregirlos o borrarlos, limitar su uso u oponerte a él, y llevarlos a otro servicio. Escríbenos desde la página de [contacto](/contacta/).

Si crees que no hemos atendido bien tu solicitud, puedes reclamar ante la [Agencia Española de Protección de Datos](https://www.aepd.es/).
