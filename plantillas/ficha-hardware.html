LEDs

Tres diodos emisores de luz (verde, naranja y rojo) que sirven como indicadores visuales. Puedes encenderlos y apagarlos o, en el verde, regular su brillo.

Echidna Black Echidna Shield

Descripción

LED son las siglas de Light Emitting Diode, diodo emisor de luz. Funcionan gracias a la electroluminiscencia: cuando circula corriente por ellos, emiten luz. Se usan como indicadores y, cada vez más, para iluminar.

Funcionamiento

Al aplicar tensión, el LED se enciende. Desde el programa podemos controlarlo de dos formas:

  • Modo digital: un 1 lo enciende y un 0 lo apaga.
  • Modo PWM: un valor entre 0 y 255 regula el brillo.

¿Por qué lleva una resistencia?

Todos los LEDs necesitan una resistencia en serie que limite la corriente. En las placas Echidna ya está incluida, así que no tienes que añadir nada.

Pines

PinColorTipo de salida
D11~VerdeDigital + PWM
D12NaranjaDigital
D13RojoDigital

El símbolo ~ indica que el pin admite PWM.

Cómo se programa

En EchidnaML hay bloques específicos para elegir el LED y su estado (encendido o apagado) o, en el verde, su intensidad de 0 a 255.

Con Arduino IDE el equivalente en código es:

void setup() {
  pinMode(13, OUTPUT);       // LED rojo
}

void loop() {
  digitalWrite(13, HIGH);    // enciende
  delay(1000);
  digitalWrite(13, LOW);     // apaga
  delay(1000);
}
